# CineNova starter website

A responsive homepage concept for CineNova — “A New World of Entertainment”, using midnight black, champagne gold, charcoal, and subtle burgundy.

## Important
This is a **front-end design prototype**, not a production streaming service. It does not yet include real accounts, payments, subscription enforcement, movie playback, or an admin dashboard. The movie cards are illustrative placeholders. Only add films and trailers you have permission to distribute or embed.

## Run locally
1. Install Node.js 20 or newer.
2. Open a terminal in this folder.
3. Run `npm install`
4. Run `npm run dev`
5. Open `http://localhost:3000`

## Deploy to Vercel
1. Create a GitHub account if you do not already have one.
2. Create a new GitHub repository named `cinenova`.
3. Upload the files in this folder to the repository (keep the `app` folder).
4. Sign in to Vercel using GitHub and choose **Add New → Project**.
5. Import the `cinenova` repository and select **Deploy**.
6. Vercel will provide a temporary public website address.

## Before launching publicly
- Check whether the CineNova name and domain can be used legally.
- Replace placeholder cards with approved content and real artwork.
- Add a secure backend/authentication provider for accounts.
- Integrate a payment provider only after deciding pricing, trial rules, refunds, and regional availability.
- Use a licensed video hosting/delivery service for video playback.
- Add privacy policy, terms, contact details, and appropriate age/content controls.
